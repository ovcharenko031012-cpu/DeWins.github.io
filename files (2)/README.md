# DeWins — как включить онлайн и ленту дропов через Google Firebase

Сервер не нужен. Firebase бесплатный (тариф Spark).

## 1. База данных
1. Открой https://console.firebase.google.com → **Создать проект** (например, dewins).
2. Слева **Build → Realtime Database → Create database**. Регион любой, режим **locked mode**.
3. Вкладка **Rules** → удали всё → вставь содержимое файла `database.rules.json` → **Publish**.

## 2. Ключи сайта
1. **Project settings (шестерёнка) → Your apps → значок `</>` (Web)** → назови приложение → Register.
2. Скопируй объект `firebaseConfig`.
3. Открой `config.js` и вставь значения в `firebase: { ... }` (нужны как минимум `apiKey`, `databaseURL`, `projectId`, `appId`).
   Эти ключи не секретные, защита делается правилами из шага 1.

## 3. Опубликовать сайт (Firebase Hosting)
    npm install -g firebase-tools
    firebase login
    firebase use --add        # выбери свой проект
    firebase deploy

После деплоя Firebase покажет адрес вида https://dewins.web.app — открой его в двух вкладках:
онлайн станет 2, а дроп из одной вкладки сразу появится в другой.

## Ограничения
- Правила проверяют формат дропа, но игра считается в браузере, поэтому выдуманный дроп отправить можно.
- Онлайн считается по открытым вкладкам; при тысячах одновременных игроков лучше свой сервер (папка `server`).
- Старые дропы не удаляются сами: очищай раздел `drops` в консоли раз в какое-то время.
